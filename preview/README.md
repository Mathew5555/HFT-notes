# Облачная навигация HFT Notes

Дополнительный интерфейс доступен по адресу `preview/` после обычной сборки MkDocs. Классический сайт сохраняет прежние адреса.

- `index.html`, `style.css`, `app.js` — экран разделов, список тем и анимация объёмных облаков с реакцией на мышь и приближением при наведении.
- `reader.html`, `reader.css`, `reader.js` — отдельное оформление конспектов, оглавление и навигация.
- `hooks/preview.py` — собирает каталог из актуальных Markdown-файлов и копирует интерфейс в результат сборки.
- `catalog.js` генерируется автоматически; редактировать или добавлять его в Git не требуется.

Для локального просмотра из корня репозитория:

```sh
mkdocs serve
```

Откройте `http://127.0.0.1:8000/preview/`. После изменения файлов в папке `preview/` перезапустите просмотр, чтобы пересобрать страницу.

Пустые конспекты отмечаются «Скоро». Готовые статьи открываются в том же окне в отдельном светлом оформлении по адресу `preview/read/…`. Вверху есть возврат в раздел, внизу — предыдущий и следующий готовый конспект. Тексты и изображения берутся из той же сборки Markdown; редактировать их копии не нужно. Анимацию можно отключить; системная настройка уменьшения движения тоже учитывается.

При отправке изменений нужны папка `preview/`, файл `hooks/preview.py` и изменение `mkdocs.yml`. Публикацию выполняет владелец репозитория.

Фактура облаков: `assets/cloud-bank.png`, создана для проекта по визуальному референсу. Без движения мыши слои медленно дрейфуют; движение мыши добавляет смещение по глубине и краткое ускорение, наведение на кнопки плавно приближает облака. Кнопки непрозрачно-белые. Папку `assets/` нужно отправлять вместе с остальным интерфейсом.
