# Линейные модели и перцептрон

Линейная модель получает вектор признаков `x = (x₁, …, xₙ)` и считает **оценку** `z = w₁x₁ + … + wₙxₙ + b`. Веса `w` и смещение `b` — обучаемые параметры. Признаки должны быть нормированы (должен совпадать масштаб, например, все `x`в диапазоне [0; 1].

## Перцептрон

Перцептрон — простой линейный бинарный классификатор. Он сравнивает оценку с порогом: `ŷ = 1`, если `z ≥ 0`, иначе `ŷ = 0`. 

### Однослойный перцептрон

У однослойного перцептрона входы сразу соединены с выходным нейроном; скрытых слоёв нет:

```text
x₁ ── w₁ ──┐
x₂ ── w₂ ──┼──► [ сумма взвешенных входов + b ] ──► [ активация ] ──► ŷ
x₃ ── w₃ ──┘                  z                         g(z)
```

На ошибочном примере с истинной меткой `y ∈ {0, 1}` классическое правило обучения поправляет параметры: `wᵢ ← wᵢ + η(y − ŷ)xᵢ`, `b ← b + η(y − ŷ)`, где `η` — шаг обучения. Такой классификатор проводит **линейную** границу.

**Вариант с L2-регуляризацией:** к функции потерь добавляют штраф `(λ/2)∑wᵢ²`, где `λ ≥ 0`. Тогда шаг обновления весов имеет вид `wᵢ ← (1 − ηλ)wᵢ + η(y − ŷ)xᵢ`. Смещение обновляют как прежде: `b ← b + η(y − ŷ)`; обычно его не штрафуют. При `λ = 0` получается исходное правило. При верном ответе поправка по ошибке равна нулю, но веса всё равно слегка уменьшаются из-за L2.

## Выходной параметр и функция активации

`z` — выход линейной части, а `ŷ = g(z)` — итоговый выход модели. Функция активации `g` задаёт его смысл:

| Активация | Выход | Типичная задача |
|---|---|---|
| `g(z) = z` | Любое действительное число | Линейная регрессия |
| `g(z) = 1 / (1 + exp(−z))` | Число от 0 до 1 | Логистическая классификация 

Сигмоида даёт оценку вероятности для заданной метки.
```python
import math

x = [0.4, -0.2, 0.5]      # три уже нормированных признака
w = [1.0, -0.5, 0.2]     # веса
b = -0.3                  # смещение

z = sum(wi * xi for wi, xi in zip(w, x)) + b
perceptron_class = int(z >= 0)
logistic_probability = 1 / (1 + math.exp(-z))

print(round(z, 3), perceptron_class, round(logistic_probability, 3))
# 0.3 1 0.574
```

Если истинная метка для этого примера равна `0`, перцептрон ошибся. Продолжение кода показывает один шаг обучения с L2-регуляризацией:

```python
y = 0
eta = 0.1
l2 = 0.1
error = y - perceptron_class
w = [(1 - eta * l2) * wi + eta * error * xi for wi, xi in zip(w, x)]
b += eta * error
print([round(wi, 3) for wi in w], round(b, 2))
# [0.95, -0.475, 0.148] -0.4
```
