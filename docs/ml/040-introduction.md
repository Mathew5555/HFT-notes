# Основные задачи машинного обучения

## Обучение с учителем

**Обучение с учителем (supervised learning)** — обучение на примерах с известными ответами. Алгоритм подбирает модель, которая по свойствам объекта предсказывает ответ для нового объекта.

Например, по площади, числу комнат и району можно предсказывать цену квартиры:

| Объект | Площадь, м² | Комнаты | Район | Цена, млн ₽ |
|---|---|---|---|---|
| Квартира A | 40 | 1 | Северный | 8 |
| Квартира B | 60 | 2 | Центральный | 15 |
| Квартира C | 45 | 1 | Северный | ? |

- **Объект** — отдельный пример: квартира.
- **Признаки `x`** — известные свойства: площадь, комнаты и район.
- **Таргет `y`** — то, что требуется предсказать: цена.
- **Обучающая выборка** — набор примеров с известными ответами.

**Модель** вычисляет предсказание `ŷ = f(x)`. **Алгоритм обучения** подбирает её параметры по обучающей выборке. `y` — известный ответ, а `ŷ` — предсказанный; они могут различаться.

```text
Обучение:     признаки x + ответы y → алгоритм обучения → модель
Предсказание: признаки нового объекта → модель → ответ ŷ
```

Цель — получать хорошие предсказания на новых данных. Запоминание обучающих примеров само по себе этого не обеспечивает.

### Классификация

**Классификация** — предсказание класса объекта.

При **бинарной классификации** классов два: например, письмо — спам (`1`) или не спам (`0`). Числа обозначают классы, а не величину ответа.

При **многоклассовой классификации** выбирается один класс из нескольких: например, кошка, собака или птица. Если объекту можно присвоить сразу несколько меток, это **многометочная классификация**: например, теги «спорт» и «политика» у одной статьи.

### Регрессия

**Регрессия** — предсказание численного значения: цены квартиры, температуры или продолжительности поездки.

Тип задачи определяется смыслом ответа: «дорогая ли квартира?» — классификация; «сколько стоит квартира?» — регрессия.

## Обучение без учителя

**Обучение без учителя (unsupervised learning)** использует объекты без заданных ответов и ищет структуру в данных.

Пример — **кластеризация**: объединение похожих квартир в группы по площади, району и другим признакам. В отличие от классификации, готовые метки групп при обучении не задаются.

## Обучение с частичным привлечением учителя

**Обучение с частичным привлечением учителя (semi-supervised learning)** использует и размеченные, и неразмеченные объекты для одной задачи.

Например, из 10 000 писем только 500 имеют метку «спам / не спам». Обучение использует эти метки, а остальные письма помогают учитывать структуру данных. Правильные ответы для них заранее неизвестны.
