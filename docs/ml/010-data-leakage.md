# Утечки данных

Data leakage возникает, когда в обучение модели попадает информация
из будущего или из тестовой выборки.

## Примеры

- нормализация по всему датасету;
- случайное перемешивание временных наблюдений;
- признаки, рассчитанные с использованием будущих цен;
- пересекающиеся интервалы между train и test;
- выбор гиперпараметров по итоговому тесту.

## Базовая защита

1. Разделять данные по времени.
2. Рассчитывать преобразования только на train.
3. Учитывать горизонт разметки.
4. Использовать purge и embargo при необходимости.
